# Synthetic Data Notice

Every file under `data/raw/` in this repository is **entirely fabricated**.
None of it comes from the lab's actual sensors or any real measurement.

It was generated by [`scripts/generate_synthetic_data.py`](../../scripts/generate_synthetic_data.py)
using simple diurnal/seasonal sine curves plus random noise, written out in
the exact raw file formats (Empower, Kissel/MXmini, Campbell Scientific
TOA5) that the ingest pipeline expects, so the full pipeline and dashboard
can be demonstrated without using any lab-owned data.

This is a portfolio/demo copy of a real pipeline built for an MSc thesis.
The real project (private, built on the lab's actual sensor data) is not
published here or anywhere public.
